# Поддержка и оставшиеся границы

Источником фактических результатов является `test-output/browser-report.json` последнего успешного запуска. Проверки выполняются на локальных синтетических роликах, не на аккаунтах реальных сервисов.

## Форматы

| Возможность | Реализация / проверка |
|---|---|
| HTTP MP4 | Полный путь от обнаружения до файла проверен |
| WebM/MOV/MKV напрямую | Реализовано сохранение исходных байтов; отдельные форматы не все проверены |
| HLS VOD | Парсер master/media, варианты, отдельное аудио; обычный VOD проверен сквозным тестом |
| HLS live | Остановка с сохранением полученной части проверяется браузерным тестом |
| HLS AES-128 identity | Передаётся встроенному демультиплексору; отдельный зашифрованный fixture пока отсутствует |
| HLS SAMPLE-AES / DRM | Отклоняется до скачивания |
| DASH static | Один Period, выбор video Representation, одна аудиорепрезентация на adaptation; SegmentList проверен |
| DASH SegmentTemplate / SegmentTimeline | Манифест передаётся движку с абсолютным BaseURL; отдельные разновидности требуют проверки |
| DASH dynamic / несколько Period | Явно отклоняются |
| Две HTTP-дорожки | Объединение видео и аудио в MP4 проверено |
| MKV | Путь выбора и muxer реализованы; следует проверять конкретные кодеки |
| DRM | Определяется по HLS key metadata / DASH ContentProtection и отклоняется |

## Сайты

| Источник из старой поставки | Новая реализация | Проверка реального сайта |
|---|---|---|
| Boosty / VK web player | Наблюдение initPlayer, playerUrls из доступного состояния/ответов, группировка по ID, качества, обложки и длительность | Два плеера с фрагментами проверены на локальной модели; закрытый пользовательский пост без авторизации не проверен |
| Kinescope / embed на Sponsr | Текущий iframe, playerOptions, одна карточка с превью, качества HLS/DASH, точные диапазоны и отдельное аудио | Открытое демо Kinescope скачано целиком; iframe проверен локально. Указанный пост Sponsr в чистом профиле требует подписку и не предоставляет плеер |
| Vimeo | playerConfig HLS/progressive + сеть | Не выполнена |
| YouTube | Открытые streamingData URL/HLS, пары adaptiveFormats, наблюдённые googlevideo-дорожки | Не выполнена; signatureCipher и отдельный decipher не реализованы |
| OK | data-options / metadata, HLS/DASH + сеть | Не выполнена |
| Facebook / Instagram | Встроенные DASH XML + сеть | Не выполнена |
| Canva | Встроенный hlsManifestUrl + сеть | Не выполнена |
| IQ | Открытый __playerdata__ с inline HLS + сеть | Не выполнена |
| VK / VK Live | Сеть и встроенный hls_ondemand | API-извлекатель старой версии не перенесён |
| Bilibili | Универсальное обнаружение манифестов | WBI/playurl и сборка пар из специализированного API не реализованы |
| Kick | Сеть и открытый playback_url | Собственный playback API и преобразование рекламных манифестов не реализованы |
| Chaturbate | Сеть и открытый hls_source | API fallback не реализован |
| Twitcasting | Универсальное сетевое обнаружение | Принудительное получение через streamserver API не реализовано |
| Osmosis | Универсальное обнаружение стандартных потоков | Перевёрнутый текст videoPlaylist не реализован |
| Javrank | Сеть | Перехват одноразового тела XHR не реализован |
| XGPlayer custom crypto | Только стандартные потоки | Специальные оболочки не реализованы |
| Taiav | Сеть и video/source | Специальная обработка миниатюр исключена |

Отсутствие специализированного API-адаптера не исключает обнаружения стандартного HLS/DASH во время воспроизведения. Оно также не гарантирует его. Загрузки, привязанные к истёкшим токенам, cookie-политикам или недоступным HTTP-заголовкам, могут завершаться ошибкой.

## Что ещё требует проверки

- Живые сайты из таблицы, включая авторизованное воспроизведение.
- Большие файлы, длительные трансляции и дисковая квота.
- Редкие HLS key formats, discontinuity, нестандартные вложенные плейлисты.
- DASH SegmentTemplate, несколько audio AdaptationSet и сложные языковые варианты.
- Полнота приватности движка на неизвестных входных данных: сетевой тест подтверждает только выполненные сценарии.

Для продолжения добавляйте отдельный fixture и критерий приёмки для каждого нового механизма. Не объявляйте полную совместимость со старой версией по одному успешному скачиванию.


## YouTube SABR — версия 1.4.0

Добавлен локально упакованный движок googlevideo 5.0.1. Он использует только успешный запрос обычного плеера открытого видео: тот же клиент, выданный плееру токен, контекст и параметры credentials. Пакеты запрашиваются через исходную страницу, видео и звук собираются в OPFS и объединяются LibAV. До начала скачивания нужно включить воспроизведение; исходная вкладка должна оставаться открыта на том же видео. Прямые эфиры SABR не реализованы; размер одного пакета ограничен 16 МБ. При HTTP 403 или требовании подтверждения движок останавливается. Генерации токенов и смены клиента нет. Реальный пример пользователя в его сессии пока не проверен.
