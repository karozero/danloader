# Danloader

Расширение для поиска и скачивания видео на странице с выбором качества и общей папки сохранения.

[English](README.md)

![preview](preview.png)

## Поддерживаемые сервисы

- YouTube
- Instagram
- Boosty
- Kinescope (включая встроенные плееры на Sponsr)

Список будет обновляться со временем

## Установка

### Chrome Web Store

Ссылка на магазин появится после публикации.

### Вручную

1. Скачайте ZIP расширения из [GitHub Releases](https://github.com/karozero/danloader/releases/latest) и распакуйте в постоянную папку.
2. Откройте `chrome://extensions` или `edge://extensions`.
3. Включите **режим разработчика** и нажмите **«Загрузить распакованное расширение»**.
4. Выберите распакованную папку, в которой находится `manifest.json`.
5. Обновите страницу с видео и включите воспроизведение.

Откройте Danloader, выберите качество и нажмите «Скачать». Папка сохранения выбирается вверху панели и применяется ко всем видео.

[Подробности поддержки](docs/SUPPORT.md) · [Результаты проверок](docs/VERIFICATION.md)

## Сборка

Нужны Node.js 22 или новее и npm. Скачайте или клонируйте исходники, затем откройте терминал в папке проекта с `package.json`:

```sh
npm ci
npm run build
```

Готовое расширение появится в `dist`. Загрузите эту папку через **«Загрузить распакованное расширение»**, как описано выше.

Команда `npm test` собирает проект и запускает модульные тесты. Проверка TypeScript: `npm run typecheck`.
